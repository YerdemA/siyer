## D. Not defteri düzeni

Gemini Notebook (eski adıyla NotebookLM) ücretsiz planda not defteri başına 50 kaynak, kaynak başına 500.000 kelime ve 200 MB sınırı uygular. Bu yüzden:

1. Tek not defteri aç: **"Siyer – Peygamberlik Öncesi"**. Sonraki dönemler için ayrı not defterleri açılır.
2. TDV madde PDF'lerini tek tek yükleme; konu başına birleştir (ör. `tdv-sahislar.pdf`, `tdv-olaylar.pdf`, `tdv-mekke-kabe.pdf`). Böylece 30+ madde 4–5 kaynak yer tutar.
3. Dosya adlarını atıfta kullanılacak biçimde ver: `ibn-hisam-sire-c1.pdf`, `ibn-sad-tabakat-c1.pdf`.
4. Çok ciltli eserlerin yalnızca ilgili ciltlerini yükle (peygamberlik öncesi: İbn Hişâm c. 1, İbn Sa'd c. 1, Taberî c. 2).
5. Aynı PDF'leri depoda `kaynaklar/` klasörüne de koy (git'e girmez). MCP bağlantısı koparsa Claude Code doğrudan dosyadan okuyabilir.
